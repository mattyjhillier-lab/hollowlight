Each weapon has a central reliquary door; each evolution is a keyhole; key teeth fill with progress.
+ Very clear "three locks" metaphor; one place per weapon to look.
− Sockets leave the emblem (the "eyes of the wolf" idea is lost); adds a new object type to draw per weapon.
C. Moon-phase sockets
Each socket is a moon that waxes with progress and turns gold when full.
+ Poetic, fits dusk-to-dawn; no clutter of numbers.
− Imprecise (players asked for visible progress); moon is the HUD timer's language, so it would mean two things.
