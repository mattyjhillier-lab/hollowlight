The Wick (Elias's companion): three look options

Sandbox only (canvas, no network). Elias, the Husk enemies and the Holy Orbit candle-flames here are the REAL game art code (src/gfx/eliasart.js, husk/*, summon/orbit.js, bundled unchanged by build-real.mjs); the Wicks use the same shape/outline/gradient/rim helpers. Sizes use the game camera rule (zoomFor; 1 du = 0.211 world units); small views are baked through a 1.25 texel/du canvas like the rig atlas. The Sanctuary Ring candles are a simple stand-in.
