# Credits

## Fonts (UI IDENTITY v1, chunk U1)
All three are SIL Open Font License 1.1, no Reserved Font Name declared. Source: github.com/google/fonts, folder `ofl/<family>/` (downloaded 2026-10-16 with Matt's approval, fetched into an empty folder outside the repo, OFL.txt read, magic bytes checked, nothing executed). Subset to Latin (Basic Latin, Latin-1, common punctuation, arrows, minus, euro) and converted to woff2 with fontTools 4.67 (build-time tool in a throwaway venv, not a project dependency); variable weight axis narrowed to the used range. Self-hosted, inlined into the single-file build; no CDN.
