# Heroes and abilities: workshop decisions (Matt decides; Claude records)

Process: research (docs/research/23) -> design -> review -> bot check -> build. Abilities must be meaningful, fit the hero, never game-breaking (CLAUDE.md principle). Bible is a starting point, not binding.

## Wren (APPROVED 2026-10-14)
- Look: Pelt Walker + ghost wolf pup (docs/mockups/wren-v2/).
- Active ability: **Rally the Pack** as the base: wolves converge on and pin the toughest enemy for about 6 s, then flare; the pup howls and the ember lantern flares amber (B's ember flavour). Not a hard lock on bosses (wolves attack, no pin). 60 s cooldown start; bounded wolf damage bonus (+50% in window as a starting number for the probe).
- **Pelt Dash** (C) becomes an UNLOCKABLE second option via the progression gates (not a default).
- Pack Howl as shipped is retired by this change (needs build + probe: must stay a modest share of Wren's power; run win rate with ability off within 5 points).
- Open: pup visual tie to Ghost Wolves rank (visual only, idea).
