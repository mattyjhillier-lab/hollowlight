## 11. ADDENDUM: what a NEW profile can pick vs what the tree unlocks, and a better First Lantern
Verified in code (src/app.js:337-362, src/meta/starter.js, src/sim/cards.js:172-173/289, balance.json `starter`):
- Starter pick screen (`ui.showStarterHero`, `chooseStarter`): offers all FIVE weapons (balance.starter.weapons) and any hero, but a new profile takes exactly ONE weapon. `grantStarter` writes that weapon's HEART node (e.g. gt_ghost_wolves) plus its first evolution gate into save.tree, bypassing the `runs>=2` condition and the 150 gold.
- Run 1 therefore has ONE weapon heart. `spiritChoices` shows the other four dim/asleep ("Wake it in the Lantern Web"); `startableWeapons` = weapons whose heart is owned. A heart ALSO feeds the level-up card pool: all five weapons have `treeGate: true`, and cards.js:172-173 only offers a gated weapon if `unlockedWeapons` (filled from owned hearts) has it; the starting weapon is held, so it is exempt.
- So Matt is half right: any weapon can be the starter (pick), but Wolves are NOT available to a player who picked Bolts: for them gt_ghost_wolves is a real 150 gold + 2 runs unlock that adds Wolves to start options and card pool. For a player who picked Wolves the node is already lit, so a "free First Lantern = wake Ghost Wolves" is either redundant (Wolves starter) or a free second weapon (all others). Both wrong. The sheet's row 1/3 and 3.1 must go.
Candidates for a genuinely new, free, exciting first lantern (ranked):
1. BEST: make the existing cheapest real option the pulsing first light and pay for it: Second Glance (sp_reroll1, 150 gold, no condition, a button you feel in run 2). Do it WITHOUT touching a released price: new profiles are created with 150 gold (or the first run's gold already covers it; ~470-700 on a loss), the tour pulses sp_reroll1, and nothing in tree-released.json changes (no version bump, no migration). Excitement = lighting your first star before/after run 1 and getting a visible new verb (reroll). Veterans get nothing new and no tour (gate on stats.runs == 0).
2. If Matt wants it truly free (cost 0): add a NEW node with a new id (append-only, nothing released changes) instead of editing sp_reroll1, e.g. a one-rank "Wick Spark" landmark that gives 1 reroll charge on its own; the old Second Glance chain then becomes the second rung. A cost edit of sp_reroll1 itself is a released-price change: needs core.version 5 + a migration that refunds 150 to players who bought it.
3. Weapon-card-pool unlock (a free second spirit): REJECT. It is exactly the heart effect, gives a power/option jump to every non-matching starter, moves the fresh-profile win band (15-30%) and needs a full re-sweep; it also removes the "wake a spirit" chase that Set A/B lean on.
