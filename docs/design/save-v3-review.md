# Save v3 + skill tree T1/T2: independent adversarial review (2026-10-18)

Scope: commits 2bc1cb0 (T1 schema/fragments/validator/budget) and aa09ae5 (T2 save v3, compact codec, Regrowth). Reviewer: fresh agent, read the code, did not trust the author's claims, tried to break it. No `src/` file was changed.

Evidence lives in two places:
- `tests/savereview.test.mjs`: one test per finding. Tests named in `KNOWN_FAILING` reproduce an OPEN finding and run as `todo` (reported, not counted as failures), so `npm test` stays green (753 tests: 745 pass, 8 todo). The fix step removes a name from `KNOWN_FAILING` when its fix lands; the test must then pass.
- `scripts/review/*.mjs`: reproduction scripts (no network; the only writes are inside a fresh `os.tmpdir()` folder that is deleted afterwards).

| Script | What it does | Result |
|---|---|---|
| `regrowth-sim.mjs [2000]` | Independent v1 buy simulator (rules re-implemented from `tests/fixtures/tree-v1.json`: requires, rivals, ranks, rankCost, shards), random histories -> v2 save -> real `parseSave` -> check gold/shards = start minus gate spend, tree = exactly the gates | 2000 histories, 0 mismatches, refunds up to 54,830 gold |

## Verified safe (currently passing regression tests R01-R07, R17-R19)

- Prototype keys (`__proto__`, `constructor`, `prototype`) at every depth incl. compact `{v,o,r}`, `seen`, `notes`, `recentRuns`: never survive, nothing polluted (R01).
- Huge/negative/float/string/bool numbers, NaN/Infinity (rejected by JSON), forged envelope versions: clamped or refused (R02).
- Base64url: invalid chars, padding, length % 4 == 1, over-long (> 4096), stray bits, empty, unknown or look-alike fragment keys, holes, inert idx: all dropped (R03).
- Regrowth refunds exactly the v1 charge (independent simulator, 2000 histories) and keeps exactly the gates, incl. Talon Mark without the Raven heart (R04).
- Replay: forged `tree.v` (null, 0, 1, 2, -1, 2.5, "2"), object-form tree in a v3 envelope and forged `notes.regrowth` cannot replay or touch the bank; `tree.v` above the data is refused (R05).
- Parse-time DoS: worst 65 ms at 200 KB, no throw, no stack overflow (R06, dos-timing.mjs).
- Codec round trip for every ownership/rank state on 82, 125 and 2000 nodes (R07, codec-roundtrip.mjs).
- Imports cannot own inert/new nodes, skip `requires`/`requiresAny`, own both rivals, or own teasers (R17); sanitize is idempotent; save/load/export/import round trip is lossless (R18).
- Fragment loader: path regex blocks `..`/`//`/absolute paths, unknown directories and kinds; no data is executed (no `eval`/`Function`, R16); `tree-validate --svg` path is constrained.
- `compileTree`: iterative DFS (no stack overflow on deep chains, existing test), cycle detection correct, overlap grid checks the 3x3 neighbourhood with an exact distance test (key collisions only add candidates, never miss one).
