## 2. Other systems that make the game feel connected

| System | What it does | Source |
|---|---|---|
| Heroes | Eight in total (console listing). Two at start, rest unlocked over time via the web/challenges. Heroes do NOT start with a weapon: you pick the starting ability, and each hero has a "starting synergy" with each ability. Each hero has passives plus one big hero ability. Distinct jobs: heal-focused, level-focused, tank, fast farmer | OFFICIAL (listing), COMMUNITY (guide), OPINION (review) |
| Abilities (weapons) | 14 base abilities, each with 2 modifiers ("mods") unlocked in-run after a set ability level. Cap level 25 per ability so you cannot take every upgrade; up to 4 abilities per run. No fusion into ultimates | OFFICIAL (listing), OPINION (review) |
| Pets | Up to 5 carried, 20 unlockable, each a buff (XP, magnet range, miner regen). Obtained from cages in-run; the web can add or remove pets from the pool (a guide exists on "pets to avoid in the skill web" to improve odds of strong ones). Mixed: players call many pets weak or unexplained, cages hard to find | COMMUNITY (guide titles, aggregator), OPINION (review) |
| Maps | Nine; unlock via the web; each with its own terrain character (open desert, walled village, dense forest) and rewards | COMMUNITY |
| Difficulty tiers | Normal (no curses) -> Hard (random curses, resource multipliers, needed for Ember) -> Brutal (much higher enemy hp/damage; single biggest complaint) -> Hardcore permadeath. Harder tiers also bring new enemies and bosses | COMMUNITY, OPINION |
| Challenges | Per-hero "build challenges" with preset builds/weapons; completing them opens web paths. Some players dislike being forced into set builds | COMMUNITY (aggregator) |
| Resource loop in a run | Mines, chests, cages and shops: you must walk to and stand near things. Gives runs a second job beyond killing and feeds the web | COMMUNITY (guide) |
| Achievements | Steam achievements track web purchases, challenges and hardcore | COMMUNITY (TrueAchievements, WeMod) |
| Not found | Daily challenges, relics/equipment slots, story drip, a shop screen beyond in-run shops. Absence of evidence only, UNVERIFIED | - |

What keeps players going (inference from sources): the web is both shop and checklist; every run pays a currency into it; special currencies tie the best nodes to harder play; heroes and maps are unlocks you can see ahead.

## 4. Does it feel connected between screens?

- Evidence: the hub is simple (Start Run / Oracle / Web). Run end -> web -> spend -> next run is a tight three-beat loop (guide). The web is the home screen, not a side menu.
- Rewards ride on top of the loop: mines and chests in the run produce exactly the currencies the web asks for, so the run's actions visibly feed the next screen.
- Connection breaks: players cannot easily see what to do next; locked nodes and challenge links are hard to read; no cause-of-death explanation on the results screen (review).
- Not found: any evidence of a story or hub-world; unverified. This is mostly an abstract board, not a place.

## 5. Takeaways for Wispwick (original lessons)

Fit rule for all: Warm Lantern look, code-drawn art, no copied layout/names. Evidence tags as above.

| # | Lesson | Do / avoid | Fit with our rules | Evidence |
|---|---|---|---|---|
| L1 | **The web is the home screen, not a menu.** Run -> results -> web is one loop | Make the tree/sky the thing you return to and spend on right after a run; avoid duplicating goal lists on several screens | Matches research 33 Q4 (tree as front door); touches locked front-door flow, needs reopen | COMMUNITY guide loop; OPINION "tangible" |
| L2 | **Scale itself feels like progress, but only if readable.** Praise and complaint come from the same size | Keep the big web (locked principle) but add structure: named districts, a bright path to the next goal, a clear "you are here" and zoom levels; avoid scattered tiers and hidden nodes | Strengthens "huge web" principle; our Next-step/Goals tabs already help | OPINION vs COMMUNITY (section 3) |
| L3 | **Runs should earn the specific thing the web wants.** Chests/mines feed runes and crystals | Tie each currency/resource to something you do in the run (we have gold + shards); consider making a second, run-flavoured resource per chapter that only the matching constellation takes; avoid one generic gold for everything | Fits Lantern Web by chapter regions; free to build; needs economy rebalance (Matt's call) | COMMUNITY guide |
| L4 | **Rarest currency from the hardest mode opens the outer ring.** Ember Cores from Hard only | Gate the "wow" outer nodes by a currency tied to night tiers (Deep Dusk, Long Night), so difficulty choice = progression choice; avoid one grind-only gate | We already have nights; fits Dusk ring of keystones in D2/D5 | COMMUNITY guide |
| L5 | **Landmarks over filler.** +1% nodes are the loudest complaint | Cut the 79 identical ring lanterns down or merge into bundled "chapter of five" nodes; every purchase should change something visible (verb, unlock, look); avoid ever-growing percent nodes | Strongly supports D2 and the landmark-first part of D5; contradicts keeping 163 nodes as-is | COMMUNITY aggregator (single source) + our H2 |
| L6 | **Locked things must be visible and their condition legible.** Poor locked-node visibility is a top tree complaint | Show locked landmarks as silhouettes with the condition icon and progress, never "???" for the whole map; our recipes-hidden rule can stay for evolution RECIPES but show that the evolution EXISTS | Partly contradicts H6 stance (hide recipes) only for visibility of the socket, not the recipe; needs Matt's call | COMMUNITY aggregator, OPINION review |
| L7 | **Challenges as unlock keys per hero.** Per-hero challenge clears open web paths | Give each hero 1-2 short "Trial" runs (fixed kit, readable goal) whose clear lights a branch; avoid forcing a build so hard it removes freedom (a stated complaint) | Fits "different heroes/builds unlock nodes" principle; build trials as optional with free pick | OPINION review, COMMUNITY aggregator |
| L8 | **Choose your starting weapon; hero identity lives in the hero ability and a synergy with that weapon.** | Consider a small hero x weapon "bond" bonus instead of fixed starting weapons; avoid making one hero a clear best | Interacts with locked character system v2 (heroes differ by ability); reopen only if Matt wants | OFFICIAL listing, OPINION review |
| L9 | **Balance of hero/weapon power defines build variety.** One hero dominated a 2022 thread; weak options dilute the pool | Keep sweeps proving small Wren/Elias gap (already a target); do not add weak filler cards that thin the pool | Matches existing balance targets | COMMUNITY Steam thread, aggregator |
| L10 | **Explain deaths and progress at the results screen.** Unexplained deaths and unclear what to do next hurt | Results screen shows what killed you, what you earned, newly lit stars, and the next goal in one panel | Cheap: pure UI text/data; fits Warm Lantern results | OPINION review |
| L11 | **Difficulty spikes at the top tier are the #1 gripe.** | Keep Long Night tuned to our locked target bands; introduce curses/multipliers gradually and show the reward multiplier before you pick | Matches nights design | COMMUNITY aggregator |
| L12 | **Pets: many options, explained badly.** | If companions arrive (QUEUE has them after the tree), cap the roster small, one clear verb each, always explained in-run | Parked feature; do not build now | COMMUNITY/OPINION |

## 6. Effect on research 33's directions (D1-D5)

- D1 Restore the Hollow sky: SUPPORTED by L1, L2, L6 (tree as home, readable structure, visible locks). Does not conflict with anything found.
- D2 Fewer/bigger: SUPPORTED by L5 (filler is the loudest complaint) but PARTLY CONTRADICTED by L2 (size itself earned praise). Resolution: keep the large feel through scale of landmarks and districts, not through hundreds of percent nodes.
- D3 Lantern Village: not tested by this evidence (their web is abstract, not a place); neither supported nor contradicted. Their web works without a place, so a village is optional spectacle, not a requirement.
- D4 Per-hero boards: MIXED. Their clusters by ability exist, but a single connected web with challenge-opened paths seems to be what reviewers loved. Supports keeping one shared web (against isolated boards).
- D5 Hybrid: remains best fit. Add L3/L4 (currencies tied to run activities and difficulty), L7 (hero trials), L10 (results screen).
- Correction to research 33 H2: the "+1%" complaint is from one aggregator summary, not many sources; keep it labelled as weak evidence.
